## 当前需要保留的验收限制

1. 各页面尚未全部完成明暗主题截图对照；默认首页和交易页面已按设备差异修复，不能据此推定其余路由一致。
2. 自定义图标受限下载／加密缓存、其余图表触摸命中和组件设置组合仍需实际操作；E16已验证API24小屏计算器，E26已验证最大字号预览／应用／重启，不能推广到所有页面和字号组合。
3. 条件功能开关、拒绝权限及失败恢复需按独立测试账本覆盖；不应用生产账本验证清理和迁移。
4. 原用户金额／时间格式已接入，仍需覆盖多语言、正负收支、跨币种及长金额布局。
5. 账户、分类、标签、分组、对账、批量迁移的最新子动作由 `catalogs` 专门审查补齐，应结合其交付记录验收，不以本清单替代。
